Edit video by asking Claude Code for it

Describe the video you want, Claude writes it as code, and an editor opens with your clip already in it. Ask for changes in plain English and it updates while you watch. Here is the whole setup, start to finish.

0 · Before you start

  • Node.js installed. Check with node --version.
  • Claude Code, opened in your project folder.
  • On Windows, put the project somewhere shallow like C:\dev\video.

1 · Create the project

npx create-video@latest --yes --blank --no-tailwind video
cd video
npm install

2 · Install the Remotion skills

These teach Claude how Remotion actually works, so it builds with the framework instead of guessing.

npx skills@1.5.20 add remotion-dev/skills --global --copy --skill "*" --agent claude-code --yes

You get 12 skills covering creating, markup, captions, the studio, rendering and more. --global means every future project has them too.

3 · Get the render browser

npx remotion browser ensure

A one time 113 MB download. Do it now so your first render doesn't stop halfway.

4 · Ask for your video

Open Claude Code in the project folder and describe what you want, in plain words. Reference the files you want to use.

Use clip.mov and hero.png from my downloads.
Build a 9:16 split screen: image across the top 30%,
video filling the bottom 70%, captions on the split line.
Open the studio when it's done.

It writes the composition and opens the preview.

5 · Ask for changes

Keep talking to it. The preview reloads as the code changes.

Make the image fill more of the top.
Now go back to 16:9.
Add captions where the split is.

6 · Export

npx remotion render MyComp out.mp4

A 10 second 1080x1920 video renders in under a minute.

If something stops

What you seeWhat to do
spawn EINVALUse the command in step 2 exactly as written.
ENOENT mentioning chrome-headless-shellRun step 3.
Same ENOENT, but the file is thereWindows path limit. Move the project somewhere shallow, like C:\dev\video.
A render taking a long timeIt runs on your machine. Longer videos take longer.

Worth knowing

  • Remotion is free for teams of 3 or fewer.
  • Your composition is a real React file. You can always open it and change it by hand.
  • Structure it the way the remotion-interactivity skill describes and edits you make in the studio write back into the code.
