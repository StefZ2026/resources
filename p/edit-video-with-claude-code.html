Edit video with Claude Code and Remotion

You describe the video you want, Claude writes it as code, and a real editor opens with your clip already in it. Here is the full setup as it stands right now on Windows, in order, with the exact errors you might hit and what each one means.

What you end up with: a real .mp4 generated from a React file, edited by asking for changes in plain English. Remotion is free for teams of 3 or fewer.

Before you start

  • Node.js — node --version should print something. This was run on v24.18.0.
  • Claude Code, opened in the folder you are about to create.
  • Windows tip worth taking: put the project somewhere shallow, like C:\dev\video, not deep inside Documents or OneDrive. Reason is in the errors table.

The sequence

1 · Scaffold the project

npx create-video@latest --yes --blank --no-tailwind video
cd video
npm install

About 360 packages. --yes keeps it non-interactive so you are not answering template prompts.

2 · Install the Remotion agent skills

These teach the agent Remotion's actual API, so it follows the framework instead of guessing at it. Remotion documents this command:

npx remotion skills add
On Windows this currently returns Error: spawn EINVAL. It is not your setup. Run the command it wraps and you get the same result:
npx skills@1.5.20 add remotion-dev/skills --global --copy --skill "*" --agent claude-code --yes

That installs 12 skills — create, markup, captions, studio, render, interactivity, maps, multimedia, docs, saas, upgrade and best-practices. --global puts them in your user profile so every future project has them. --copy writes real files rather than symlinks into the project folder, which is what you want if that folder ever moves or gets deleted.

3 · Get the render browser

npx remotion browser ensure

Pulls a 113 MB Chrome Headless Shell. Do this before your first render or it stops on ENOENT looking for an .exe that was never downloaded.

4 · Ask for the video

Open Claude Code in the project folder and describe what you want in normal words. The skills from step 2 pick themselves up, so there is nothing special to type first.

Use the two files in my downloads — clip.mov and hero.png.
Build a 9:16 split screen: image across the top 30%,
video filling the bottom 70%, captions on the split line.
Open the studio when it is done.

It writes a React component, registers it as a composition and starts the preview. Revisions work the same way — "make the image fill more of the top", "go back to 16:9" — and the studio hot-reloads as the code changes.

5 · Preview and render

npx remotion studio --no-open      # preview at localhost:3000
npx remotion render MyComp out.mp4 # write the file

A 10-second 1080×1920 composition rendered in well under a minute and came out at 8.8 MB.

If something stops, here is what it means

What you seeWhat it isWhat to do
spawn EINVAL from remotion skills add The command calls npx.cmd without a shell, and Node blocks that on Windows since the CVE-2024-27980 patch. Nothing to do with your machine. Use the npx skills@… line in step 2.
Render stops, ENOENT on chrome-headless-shell.exe The render browser has not been downloaded yet. npx remotion browser ensure
Same ENOENT — but the file is sitting on disk MAX_PATH. Windows caps paths at 260 characters. From a deep folder the shell's own path came to 308, and Node could not launch it. Move the project somewhere shallow. C:\dev\video keeps the whole path near 139.
A slash command from a tutorial is not in your autocomplete Anything tagged (user) lives in that person's own ~/.claude/commands/. Handy, but personal to their setup. Describe what you want in plain language instead, as in step 4. Same outcome.

Worth knowing before you commit an afternoon

  • Remotion is free for teams of 3 or fewer; bigger teams need a licence.
  • The composition is a real React file you own, so when the agent gets something wrong you can open it and fix it yourself.
  • Rendering happens on your machine. Long videos take real minutes and real CPU.
  • Structure the markup the way the remotion-interactivity skill describes and edits you make in the Studio write back into the code.
Every command, version number and error string above came back on a Windows 11 machine in August 2026. Tooling moves fast, so if something has shifted since, the errors table is the part that will still tell you where you are.
