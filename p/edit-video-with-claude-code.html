Mac & Windows · checked August 2026

Edit video by asking Claude Code for it

Describe the video you want, Claude writes it as code, and a real editor opens with your clip already in it. Ask for a revision and it updates in front of you.

Huge thanks to @maverickgpt for the find. Tooling has moved since, so the few pieces this now needs to reach a finished render are marked UPDATED.

What you need first

  • Node.js — node --version should print something. This run used v24.18.0.
  • Claude Code, opened in your project folder.
  • On Windows, keep the project shallow — C:\dev\video, not buried in Documents or OneDrive. Why is in the errors table.

The 3 steps

1 · Open the Claude desktop app and select Code

Point it at the folder you want the project in. If you use Claude Code in a terminal or in your editor instead, that works the same way from here.

2 · Google Remotion, copy the command, paste it into Claude and hit enter

The command on the Remotion home page is the one he copies:

npx create-video@latest

To skip the template prompts entirely:

npx create-video@latest --yes --blank --no-tailwind video
cd video
npm install
Updated · add this before step 3
Remotion now ships agent skills that teach Claude its actual API rather than letting it guess. Installing them is what makes step 3 behave the way it does in his video:
npx remotion skills add
On Windows that returns Error: spawn EINVAL. It calls npx.cmd without a shell, which Node blocks since the CVE-2024-27980 patch. Run the command it wraps and you get the identical result:
npx skills@1.5.20 add remotion-dev/skills --global --copy --skill "*" --agent claude-code --yes
Either way you get 12 skills — create, markup, captions, studio, render, interactivity, maps, multimedia, docs, saas, upgrade, best-practices. --global makes them available to every future project; --copy writes real files instead of symlinks, so nothing breaks if the project folder moves.
Updated · one more, or the render stops
Fetch the render browser once, up front. Without it the first render halts on ENOENT looking for a file that was never downloaded. It is a 113 MB one-time pull.
npx remotion browser ensure

3 · Open a new tab, call the Remotion command, and tell it exactly what you want

Then reference the file you want to use, the way he does:

clip.mov hero.png — find these two files in my downloads and use
Remotion to overlay them into a split screen. Open the editor as well.
Updated · if that command is not in your autocomplete
Slash commands shown with a (user) tag are saved in that person's own ~/.claude/commands/ folder, so a fresh install will not have one. You do not need it — with the skills from step 2 installed, describing the job in plain language reaches the same place. Drop the slash command and keep the rest of the sentence exactly as it is above.

Claude writes a React component, registers it as a composition and opens the studio. Revisions work the way he shows — "make the image fill more of the top", "go back to 16:9" — and the preview hot-reloads as the code changes.

Preview and export

npx remotion studio --no-open      # preview at localhost:3000
npx remotion render MyComp out.mp4 # write the file

A 10-second 1080×1920 composition rendered in well under a minute and came out at 8.8 MB.

If something stops, here is what it means

What you seeWhat it isWhat to do
spawn EINVAL from remotion skills add Windows only. The command calls npx.cmd without a shell and Node blocks that. Use the npx skills@… line in step 2.
ENOENT on chrome-headless-shell The render browser has not been fetched yet. npx remotion browser ensure
Same ENOENT — but the file is on disk Windows only. MAX_PATH. Paths cap at 260 characters, and from a deep folder the browser's own path came to 308, so it could not launch. Move the project somewhere shallow. C:\dev\video keeps the whole path near 139.
Nothing renders and no error is obvious Rendering runs on your machine, not in the cloud. Give it real time on longer compositions before assuming it hung.

Worth knowing

  • Remotion is free for teams of 3 or fewer; larger teams need a licence.
  • The composition is a real React file you own, so when the agent gets something wrong you can open it and fix it directly.
  • Structure the markup the way the remotion-interactivity skill describes and edits you make in the Studio write back into the code.
Every command, version number and error string above came back on a real run in August 2026. The Windows-specific notes were hit and fixed on Windows 11; the underlying cause of each is in the table so it stays useful as the tooling moves.
