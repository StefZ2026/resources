AI STRATEGY  ·  BUILD  ·  SCALE

Describe the video you want, Claude writes it as code, and an editor opens with your clip already in it. Ask for changes in plain English and it updates while you watch. Every command below has a copy button — nothing here needs typing.

Before you start

  • Node.js installed — check with node --version
  • Claude Code, opened in your project folder
  • On Windows, keep the project path short — C:\dev\video

1  Create the project

npx create-video@latest --yes --blank --no-tailwind video
cd video
npm install

2  Install the Remotion skills

These teach Claude how Remotion actually works, so it builds with the framework instead of guessing. You don’t call them — Claude picks the right one from what you ask for.

npx skills@1.5.20 add remotion-dev/skills --global --copy --skill "*" --agent claude-code --yes

You get 12 skills covering creating, markup, captions, the studio and rendering. --global means every future project has them too.

3  Get the render browser

npx remotion browser ensure

A one-time 113 MB download. Do it now so your first render doesn’t stop halfway.

4  Ask for your video

Open Claude Code in the project folder and just ask, in plain words, referencing the files you want it to use.

Make me a Remotion video.
Use clip.mov and hero.png from my downloads.
9:16 split screen: image across the top 30%,
video filling the bottom 70%, captions on the split line.
Open the studio when it's done.

5  Ask for changes

Keep talking to it. The preview reloads as the code changes.

Make the image fill more of the top.
Now go back to 16:9.
Add captions where the split is.

6  Export

npx remotion render MyComp out.mp4

A 10-second 1080×1920 video renders in under a minute.

If something stops

What you seeWhat to do
spawn EINVAL Run the step 2 command exactly as written.
ENOENT mentioning chrome-headless-shell Run step 3.
The same ENOENT, but the file is right there Windows path limit. Move the project somewhere shallow, like C:\dev\video.
A render taking a while It runs on your machine. Longer videos take longer.

Worth knowing

  • Remotion is free for teams of three or fewer.
  • Your composition is a real React file — you can always open it and change it by hand.
  • Structure it the way the remotion-interactivity skill describes and edits you make in the studio write back into the code.
